# Автоматизированное формирование концепции территории ЦОД

MVP программного инструмента для автоматизированного формирования концепции развития территории центра обработки данных.

## Назначение

Приложение позволяет сформировать предварительную схему размещения основных объектов ЦОД с учетом исходных параметров участка, мощности ИТ-нагрузки и нормативных ограничений.

## Основные объекты

- здание ЦОД;
- ГПП;
- кДГУ;
- КПП;
- парковка;
- внутренние дороги;
- инженерные сети.

## Технологии

- Python
- Streamlit
- GeoPandas
- Shapely
- Plotly

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Проект разработан в рамках НИР.
