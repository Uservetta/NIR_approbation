# Автоматизированное формирование концепции участка ЦОД

MVP программного инструмента для автоматизированного формирования концепции размещения объектов дата-центра на земельном участке.

## Назначение

Приложение позволяет сформировать предварительную схему размещения основных объектов ЦОД с учетом исходных параметров участка, мощности ИТ-нагрузки и нормативных ограничений.

## Основные объекты

- здание ЦОД;
- ГПП;
- топливное хозяйство ДГУ;
- КПП;
- парковка;
- внутренние дороги;
- инженерные сети.

## Технологии

- Python
- Streamlit
- GeoPandas
- Shapely
- Plotly

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Проект разработан в рамках НИР.
